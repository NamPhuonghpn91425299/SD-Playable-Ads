# How To Setup Aircraft Y8-01

## Overview
Setup guide for Aircraft_Y8_01 prefab configuration.

## Setup Steps

### 1. Basic Configuration
- phải có ít nhất 1 điểm đặt type = Aircraft_Y8_01
- tạo thêm điểm đặt type = infantry
- kéo các điểm đặt infantry vừa tạo vào pointChidCanMove của Aircraft_Y8_01, nó sẽ tương ứng với các index spawn ra
